# EasyCRM portfolio summary

EasyCRM is a locally verified portfolio MVP joining multi-tenant CRM, approved business knowledge, structured AI qualification and human-controlled messaging. It extends one React/TypeScript + FastAPI/SQLAlchemy/PostgreSQL application with versioned Alembic migrations; no parallel framework or autonomous-agent service is introduced.

## Technical highlights

- Opaque hashed sessions, Argon2 passwords, membership/admin guards and composite tenant foreign keys, with cross-workspace negative tests.
- Server-only Gemini/NVIDIA credentials and durable per-workspace provider/model settings. Discovery, explicit inference testing and generation have distinct sanitized failure states.
- Review-first website/PDF ingestion into the existing source store; pinned public HTTPS fetches, bounded Poppler extraction, tenant-filtered lexical retrieval and verbatim citation validation.
- Immutable rubric versions, evidence-checked structured facts and deterministic points. Scores are rubric matches, not purchase probabilities. Unsupported policies and unsafe instructions escalate.
- HMAC/replay-protected website/Meta intake, PostgreSQL inbox/outbox, conservative retries, visible failed/ambiguous work and final dispatch checks for control version, opt-out and messaging window.
- UTC cohort analytics from actual records, shared database throttling, readiness/worker heartbeat, generated correlation IDs, sanitized logs and audited admin subject export/erasure.
- Compiled SPA/Nginx production configuration, unprivileged constrained API/worker containers, migration ordering, backup/restore instructions, fixture evaluation and browser flows.
